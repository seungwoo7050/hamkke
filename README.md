# Hamkke (함께)

장거리 연애(LDR) 커플을 위한 2인 전용 프라이빗 앱.

프로젝트 문서는 [`CLAUDE.md`](CLAUDE.md)와 [`docs/`](docs)를 참고할 것 (PRD, 아키텍처, 디자인 시스템, 개발 워크플로우, 커밋 청사진).

## 개발

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000)에서 확인.

정식 README(설치/배포/아키텍처 요약)는 `docs/COMMIT_PLAN.md` Phase 8에서 작성한다.
